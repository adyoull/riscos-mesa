RISC3D client library 0.8 (13 November 2026), for riscos-mesa's EGL
====================================================================

RISC3D's front end for RISC OS programs: the GL functions as commands for
the RISC3D module (r3d_glXxx, listed by name in r3d_gl_functions[]), and
contexts. Source and a prebuilt static library, from RISC3D's repository
at tag v0.8 (RiscOS/RISC3D/risc3d.bundle). MIT licence (LICENSE).

  lib/r3d.h          the interface (all EGL needs)
  lib/r3d_gl.c       the library; it #includes lib/r3d_dsa.c,
                     gen/client_gen.c and gen/r3d_exts.h
  gen/               generated by RISC3D's proto/gen.py from Khronos's
                     gl.xml (r3d_gl.h: types, enums; r3d_ops.h: opcodes;
                     r3d_exts.h: the extensions the stream carries)
  proto/r3d_shared.h the memory shared with the renderer
  libRISC3D.a        built with riscos-crossdev 1.11's GCC 10:
                     -O2 -mfpu=vfpv3 -mfloat-abi=hard (not PIC)

New in 0.8:
  r3d_driver_flags ()             RISC3D_Info's flags for the driver a new
                                  context would get, or -1 if none.
                                  R3D_DRIVER_SOFTWARE (2): it draws in
                                  software now (needs RISC3D module 0.03,
                                  Linux3D 0.02, rol-3d 0.7: riscos-risc3d
                                  0.7-1; never set otherwise).
                                  R3D_DRIVER_DRM (1): a DRM device.

New in 0.7:
  r3d_target (ctx, buffer, w, h, format, row_length, y_up)
  r3d_target_copy (ctx)           the program's own buffer as framebuffer
                                  0, OSMesa's way: copied at glFinish and
                                  glFlush (if anything was drawn since), in
                                  OSMesa's formats (RGB and BGR as
                                  riscos-mesa's 20.3.5 has them). Needs
                                  rol-3d 0.4 or later.
  C library                       no functions beyond 0.4's (nm -u is
                                  0.4's list)

New in 0.6:
  GL_EXT_direct_state_access      its 255 functions (1189 functions, 484
                                  other names): with it the library has
                                  every function riscos-mesa's Mesa
                                  20.3.5 offers. Offered with rol-3d 0.6
                                  or later (riscos-risc3d 0.6-1); with
                                  rol-3d 0.5, 0.5's list
  GL_VERTEX_ARRAY_SIZE and the    the fixed-function arrays' sizes, types
  like                            and strides answered from the state kept
                                  here

New in 0.5:
  r3d_create_version (api, major, minor)
                                  a context of at least that version:
                                  R3D_API_GL up to 3.1, R3D_API_GLES2 for
                                  GLES 2.0 to 3.1 (rol-3d 0.5 or later:
                                  riscos-risc3d 0.5-1). 0 and r3d_error
                                  ("RISC3D's renderer gives ...") if lower
  989 functions, 467 other names  OpenGL 3.0/3.1 and GLES 3.0/3.1's, and
                                  the rest of riscos-mesa's GL 2.1
                                  extensions (not EXT_direct_state_access)
  glGetString (GL_VERSION)        the version the context gives: the lower
                                  of the renderer's and the stream's (3.1),
                                  so a GLES 2 context says "OpenGL ES 3.1
                                  RISC3D (...)", as Mesa gives ES 3 for an
                                  ES 2 request; GLSL "1.40" / "OpenGL ES
                                  GLSL ES 3.10"; glGetStringi,
                                  GL_NUM_EXTENSIONS, GL_MAJOR/MINOR_VERSION
  with rol-3d 0.4                 0.4's versions and extensions

New since 0.2 (0.3 was the riscos-risc3d package only):
  r3d_create_es1, r3d_open_es1    OpenGL ES 1.1 contexts (rol-3d 0.4 or
                                  later: riscos-risc3d 0.4-1)
  704 functions, 400 other names  GLES 1.1's, and the extensions riscos-
                                  mesa offers in GLES 1.1 and 2.0 (by the
                                  extensions' names too)
  r3d_available                   reads RISC3D$Disable with OS_ReadVarVal

New in 0.2:
  r3d_overlay, r3d_swap_overlay   zero-copy frames on a display plane
                                  (see r3d.h; needs rol-3d 0.2 and rol-fb
                                  with several overlays)
  glGetString                     "2.1 RISC3D (...)" / "OpenGL ES 2.0
                                  RISC3D (...)", GLSL 1.20 / ES 1.00;
                                  GL_EXTENSIONS trimmed to the stream

To build it yourself (static, or with -fPIC for a shared libEGL):

  arm-riscos-gnueabihf-gcc -O2 -mfpu=vfpv3 -mfloat-abi=hard [-fPIC] \
    -Iinclude -Ilib -Igen -Iproto -c lib/r3d_gl.c

It needs UnixLib (swis.h, kernel.h, libm). It defines no gl* symbol: every
GL function is r3d_glXxx, so it links beside Mesa's.
