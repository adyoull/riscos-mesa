RISC3D client library 0.1 (12 November 2026), for riscos-mesa's EGL
====================================================================

RISC3D's front end for RISC OS programs: the GL functions as commands for
the RISC3D module (r3d_glXxx, listed by name in r3d_gl_functions[]), and
contexts. Source and a prebuilt static library, from RISC3D's repository
at tag v0.1 (RiscOS/RISC3D/risc3d.bundle). MIT licence (LICENSE).

  lib/r3d.h          the interface (all EGL needs)
  lib/r3d_gl.c       the library; it #includes gen/client_gen.c
  gen/               generated by RISC3D's proto/gen.py from Khronos's
                     gl.xml (r3d_gl.h: types, enums; r3d_ops.h: opcodes)
  proto/r3d_shared.h the memory shared with the renderer
  libRISC3D.a        built with riscos-crossdev 1.11's GCC 10:
                     -O2 -mfpu=vfpv3 -mfloat-abi=hard (not PIC)

To build it yourself (static, or with -fPIC for a shared libEGL):

  arm-riscos-gnueabihf-gcc -O2 -mfpu=vfpv3 -mfloat-abi=hard [-fPIC] \
    -Iinclude -Ilib -Igen -Iproto -c lib/r3d_gl.c

It needs UnixLib (swis.h, kernel.h, libm). It defines no gl* symbol: every
GL function is r3d_glXxx, so it links beside Mesa's.
